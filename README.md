This code was used to simulate data and run the analyses described in Shepta et al. (2026) A dynamic multi‐scale occupancy model to estimate trends in habitat use in spatially and 
temporally complex systems. Methods in Ecology and Evolution, 17(3), 914-928. Data simulation (1a - 1e) was used to simulate data across 22 different data-generating scenarios to validate
model structure, understand how parameter estimates and confidence intervals change under different levels of spatial and temporal replication, and investigate model performance 
under different potential patterns in occurrence data. Empirical data collected on adult Silver Carp in the Ohio River was then used as an applied example (2a - 2d) to explore model
performance using a real-world dataset. We used a spatial autocovariate and explored trends in Silver Carp turnover rates at different spatiotemporal scales.
